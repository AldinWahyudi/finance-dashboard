# Sample CSVs

Small synthetic statements covering the four supported bank formats.
Use these to smoke-test the import flow:

1. Sign up for an account.
2. Go to **Import CSV**, pick one of these files, and upload.
3. The importer will auto-detect the bank and normalize rows.

Files:

- `bca_sample.csv`
- `mandiri_sample.csv`
- `bni_sample.csv`
- `bri_sample.csv`
